# Карта спецификаций

Актуальный отчёт о частичной реализации: [KHL_IMPLEMENTATION_STATUS](../docs/KHL_IMPLEMENTATION_STATUS.md). Дальнейший текст описывает исходный пакет спецификаций.

Дата: 2026-09-07. Этот пакет описывает планируемый модуль Fantasy КХЛ. Реализация и деплой не выполнены и не входят в текущую задачу. Prist не используется по прямому указанию пользователя.

Структура `specs/common`, `specs/modules/<module>`, типы FEAT/INFRA, `status: draft`, явные якоря и адреса `spec://` следуют существующим спецификациям исходного checkout. Его отсутствующие здесь спецификации Machete не копируются и не отменяются. При интеграции добавить строки КХЛ в существующую карту, сохранив остальные записи.
