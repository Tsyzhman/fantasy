# WI-027: Понятные графики и гипотезы отчёта франшиз

- Kind: `research`
- Canon action: `none`

## Outcome

Существующий локальный отчёт читается без расшифровки номеров франшиз и неоднозначных терминов; гипотезы отклонений от ALT/ФО/FFO исследованы без объяснения бюджетом.

## Specs

- Контекст: `NEW_DESIGN.md`, `docs/DATA_MODEL.md`.
- Follow-up: `WI-025`, локальный исследовательский артефакт без изменения production-кода.

## Scope

- In: названия на графиках, явно подписанные сравнения владения, назначение рейтинга, простой язык, дополнительные проверки предматчевых признаков по сохранённой статистике, обновление всех HTML и архива.
- Out: публикация на сервере, обновление среза данных, бюджетные гипотезы, изменение формулы рейтинга.

## Acceptance

- [x] На графиках франшизы подписаны названиями; подписи читаются и не перекрываются.
- [x] База сравнения указана явно; общий H2H ориентир не смешан со средним 11 франшиз.
- [x] Рейтинг назван рейтингом склонности к редким выборам; значения объяснены простым языком.
- [x] Бюджетные гипотезы удалены; другие гипотезы проверены численно без будущих матчей.
- [x] Автономный HTML, отдельные страницы и архив обновлены и проверены; лишние копии и память контролируются.

## Result

Обновлены исходные локальные файлы `output/franchise-report-2026-27/report.html`, отдельные HTML и `franchises-2026-27.zip`. Числа на точках заменены 22 полными названиями франшиз с линиями к точкам. Подписи не пересекаются; на телефоне графики заменены таблицами с теми же значениями. Рейтинг прямо назван рейтингом склонности к редким выборам; формула и порядок мест сохранены. Добавлено простое объяснение владения, капитанства и H2h-Δ.

Было: тепловая карта `own_cohort_gap` относительно средних составов 11 франшиз. Стало: карта `own_gap` относительно общего H2H-ориентира, рассчитанного по владению всех участников с поправкой на позиции. Приближённость сравнения из-за владения всего 15-местного ростера объяснена под таблицей. Рейтинговая формула по-прежнему использует исходный компонент относительной редкости среди 11 франшиз; это явно указано в методике.

Бюджетные объяснения удалены. Проверены шесть других признаков по сохранённой статистике строго до тура: рост минут, рост формы, сложный соперник, редкость игрока, рост xG+xA/90 и недореализация моментов. Контрольные покупки сопоставлены по чемпионату, туру и позиции, одинаковые игроки-тур объединены, нужно минимум три контрольных футболиста. Выведены 44 карточки гипотез с долями, количеством наблюдений, примерами и пределами выводов. Для xG/xA недостаток данных раскрыт. У Мачете рост минут встречается в 51% отклоняющихся покупок против 27% контроля, рост формы — 33% против 19%; поиск редких игроков сам по себе не выделяется (54% против 56%). Причинность и намерение менеджеров не утверждаются.

Проверено: 13 разделов автономного файла, 13 физических страниц, сортировка и экспорт, отсутствие ошибок JS и внешних запросов, ширины 390/1440, 22 читаемые подписи, 44 карточки гипотез, каждая ячейка карты соответствует `own_gap`, все локальные ссылки действительны. HTML совпадают с версиями внутри ZIP, контрольные суммы актуальны, дублей ZIP нет. Исходный кэш читался из архива в памяти без распаковки и новых запросов к серверу; временный просмотр закрыт.
