# WI-026 — Экономное ежечасное обновление КХЛ на сервере

Kind: change
Canon action: direct-edit

## Outcome
Сервер самостоятельно обновляет доступную статистику КХЛ каждый час в :22 без браузера, с ограниченными ресурсами и явным покрытием полей БД.

## Specs
- Governing: spec://modules/khl/INFRA-001-khl-data-ingestion#runtime
- Governing: spec://modules/khl/INFRA-001-khl-data-ingestion#protocols
- Governing: spec://modules/khl/INFRA-002-khl-storage-and-api#schema
- Affected: spec://modules/khl/FEAT-003-khl-projections-and-optimizer#rolling-beta

## Scope
In: проверенный HTTP-транспорт, комбинирование доступных источников, инкрементальные загрузки, расписание, ресурсные ограничения, проверки и production.
Дополнение пользователя 20 сентября: «ПРОВЕРЬ и всех игроков и корректно замапь, обычно дата рождения сильно помогает!» Проверить весь активный пул, существующие и недостающие KHL ID по независимым датам рождения Sports/КХЛ; исправить доказанные связи и повторно импортировать затронутые матчи. Тирни уже связан: Sports 1896181/tag 161008635 ↔ KHL 44593, DOB 1994-07-01 и точное совпадение пяти матчей.
Out: браузер на сервере, покупка подписок, выдуманные значения отсутствующих метрик, изменение пользовательских сценариев.

## Acceptance
- [x] Поля текущей БД сопоставлены источникам; неизвестное не заменяется нулём.
- [x] Транспорт проверен с production; браузер не устанавливается и не запускается.
- [x] Таймер на сервере активен каждый час в :22; конкурентные циклы исключены.
- [x] Повторная загрузка идемпотентна; архив и неизменённые данные не перекачиваются каждый час.
- [x] Проверены ошибки источников, тесты, ресурсы, кэш, дубли и production-состояние.
- [x] Каждый активный игрок включён в отчёт сверки идентичности; дата рождения подтверждается независимыми источниками, конфликты не объединяются автоматически, доказанные связи применены и статистика пересчитана.

## Result
Завершено 2026-09-20. Production 0.3.83 / cb2877e338e89b9084483e60af45dc9c76ec6a76, canonical deploy https://github.com/Tsyzhman/fantasy/actions/runs/35526328946. Браузер не запускался. Таймер активен каждый час в :22 МСК, автоматический запуск 20:22 подтверждён; после последнего выпуска вручную запущен и завершён цикл за 29 секунд.

Проверены 697 карточек (695 активных + 2 неактивных), даты рождения подтверждены у всех; 691 KHL ID, 103 новых связи. Шесть несовпадений DOB разобраны по официальным биографиям/матчам; шесть молодых игроков без доступной карточки КХЛ оставлены явно несвязанными. Тирни: восстановлены пять матчей, затем автоматически загружен шестой; PP/PK/ВВА/SOG и остальные доступные протокольные поля заполнены 6/6.

65 текущих протоколов повторены дважды: changed=161, затем 0. Следующий цикл добавил три новых матча: 68 протоколов / 4313 строк. Архив: 748 матчей, расширены 41 ранее неполная история, дополнены 16 отсутствовавших историй активных игроков и 2 неактивных; всего 558 архивов (556 активных). FP отсутствующего Sports не выдумываются; KHL-only архив не подменяет полный знаменатель участия.

Проверки: CI 1145 pass / 0 fail / 0 skip, 4 Python transport tests, typecheck/build, lint 0 errors / 152 warnings. Regression проверяет создание официального архива, replay, защиту Sports FP и отсутствие ложного prior участия. DB regression для изоляции неполных строк добавлен, локально не запускался: Docker daemon недоступен. На production подтверждено продолжение загрузки при 18 противоречивых свежих строках Sports. Протоколы КХЛ успешно импортированы; 16 архивных карточек Sports остаются невалидными по идентичности, официальный архив их покрывает без FP. Эти ограничения честно дают PARTIAL. ixG/PP1/PP2/будущий starter/fullGame остаются неизвестными при отсутствии проверенного источника.

Ресурсы: кэш 816 payloads / 11.28 MiB (лимит 250 MiB / 7 суток), дубли stat/raw/активных задач=0; Node heap ограничен 384 MiB, разовый архивный backfill peak sampled RSS 241 MiB / 558 секунд; после завершения отдельного процесса КХЛ нет. 14-дневный soak не заявляется выполненным. Удаление собственных временных диагностических файлов отклонено automatic approval review: blocked by policy; повторных попыток обхода нет, рабочая retention выполняется.
