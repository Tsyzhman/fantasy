# WI-028: Аналитика франшиз с диапазоном туров и xФО

- Kind: `change`
- Canon action: `new-spec`

## Outcome
Отдельный модуль «Франшизы» в Fantasy рассчитывает аналитику за выбранные чемпионаты и туры без ИИ; локальный отчёт дополнен франшизой 23 и xФО.

## Specs
- Governing: `spec://modules/franchises/FEAT-005-franchise-analytics#root`
- Affected: `spec://modules/franchises/FEAT-005-franchise-analytics#root`
- Existing constraints: `specs/common/main.md`, `specs/common/structure.md`, действующая авторизация сайта.

## Scope
- In: воспроизводимый сбор H2H и серверной статистики, 12 франшиз сезона 2026/27, выбор диапазона, владение/капитаны/покупки/форма/модели/заморозки/xФО, общий доступ внутри Fantasy, локальный HTML.
- Out: изменение алгоритмов ALT/ФО/FFO, передача управления составами, LLM-зависимости.

## Acceptance
- [x] Формула xФО разобрана и проверена на Excel; расхождения сохранённых значений раскрыты.
- [x] Все 12 франшиз входят в воспроизводимый сбор; история решений не использует будущие матчи.
- [x] Выбор лиг/туров пересчитывает показатели, рейтинги и заморозки, пустые данные показаны явно.
- [x] Модуль доступен вне Machete; права чтения не ограничены франшизой пользователя.
- [x] Покрытие xФО показано, частичные суммы не выданы за полный результат состава.
- [x] Проверены расчёты, API, интерфейс, темы, мобильный вид и обязательные проверки проекта.
- [x] Локальный отчёт и архив обновлены; кэш, дубли и память проверены.

## Result
Добавлен самостоятельный защищённый модуль `/franchises`: чемпионаты и диапазон туров, 12 франшиз, менеджеры, текущие и исторические модели, шесть гипотез без бюджета, xФО и заморозки. H2H-решения сохраняются в PostgreSQL; фильтрация работает на готовом снимке без ИИ и внешних запросов. Восстановление 8 112 составов и 65 пулов из БД проверено. Повторные импорты не создали дублей.

Локальный HTML содержит 14 внутренних страниц / 15 HTML-файлов, включая Fratelli и xФО. Составы: 8 112; покупки: 19 614; полностью сопоставимые xФО XI: 3 741. Капитанские очки H2H уже удвоены; подтверждённые невыходы с пустым текстом распознаны по явному статусу. Два XI без полного факта H2H исключены из рейтинга сравнения.

Проверки: `npm run check` прошёл (1 149 тестов, один пропуск, lint 0 ошибок / 201 предупреждение, typecheck и production build); после форматирования повторно проверены типы и целевой lint (0 ошибок / 49 предупреждений локализации). Python: шесть тестов, 107 строк Excel, пороги 59/60 минут. API: аноним 401, плохой диапазон 400, обычный USER/BALTIKA видит все 12 франшиз; Англия 2–3 даёт 256 составов. Проверены Fratelli, заморозки Мачете в Эредивизи-7, пустая дистанция, светлая/тёмная темы, ширины 1440/390. По 12 прямых подписей на график, пересечений нет. Будущая история и дубли: 0.

Удалены 195,6 МиБ воспроизводимых промежуточных файлов и старый архив расчётов; тестовые процессы остановлены. Автопроверка отклонила рекурсивное удаление двух временных каталогов QA без подробного объяснения; они сохранены. Evidence: `specs/work/evidence/WI-028-franchise-analytics.json`.

Версия проекта 0.3.84. Код, миграция, runtime и таймер подготовлены локально. Production не изменялся, таймер не включён; статический отчёт на сервер не размещён.
