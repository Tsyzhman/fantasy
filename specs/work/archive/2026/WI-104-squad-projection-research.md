# WI-104: Проверить и добавить модели фэнтези-прогнозов в Squad

- Kind: change
- Canon action: direct-edit

## Outcome

Squad показывает до пяти новых прогнозов Sports.ru, отобранных на фактах текущего сезона, с воспроизводимым сравнением с ФО и Альт.

## Specs

- Governing: `spec://modules/machete/FEAT-001-global-ranking-strategy#research-forecasts`
- Constraint: `spec://common/INFRA-006-continuous-deployment#root`

## Scope

- In: открытые источники, хронологическое воспроизведение туров 2026/27, сравнение с официальными очками, отобранные модели и колонки Sports.ru Squad, проверка и выкладка.
- Out: изменение формул ФО/Альт, FFO, целей оптимизатора, правил подсчёта и архивных снимков.

## Acceptance

- [x] В отчёте есть веса, источники, разные семейства гипотез, покрытие и независимый от отбора поздний период.
- [x] В Squad выбранные прогнозы сортируются, фильтруются и экспортируются; другой тур и отсутствие данных не показывают старый прогноз.
- [x] Точная версия доступна в production, прогнозы опубликованы в существующем пуле без дублей.

## Result

Исходная ветка: `1ab663a`. Production до изменений: `0.3.161 / 866b1aa`.

[Отчёт](../../../../docs/research/SQUAD_FORECASTS_2026-11-13.md) и [метрики](../../../../docs/research/SQUAD_FORECASTS_2026-11-13.results.json): 97 пригодных турниро-туров, 10 гипотез, пять колонок, 22 157 строк отложенной проверки. 117 целевых тестов, полный локальный `npm run check` и шесть существующих браузерных сценариев прошли.

В production работает `20261113T162207Z-v0.3.164-f6c6d94`: `/api/health`, метка релиза и OCI web/worker совпадают. [Dry run](https://github.com/Tsyzhman/fantasy/actions/runs/43456272128) и [выкладка](https://github.com/Tsyzhman/fantasy/actions/runs/43460643051) прошли; первая передача по HTTPS вернула `CI_ARTIFACT_ERROR download` до переключения, повтор использовал штатный `operator-prestage` с проверкой хеша на обеих сторонах.

Пул обновил 12 турниров: 8 470 уникальных строк с пятью числовыми прогнозами первого тура, по три READY-ревизии на турнир, очередь пуста. Поле занимает в среднем 247 байт JSON на игрока за весь сохранённый горизонт. В браузере Squad АПЛ показал те же пять значений на десктопе и при 390 px; сортировка Ridge и диапазонный фильтр сработали, скачанный XLSX содержит те же пять чисел. У Холанда ФО 6,23 и Альт 6,98; новые значения 4,41 / 5,07 / 5,50 / 5,93 / 5,80. Временная сессия QA удалена.

401 пара запросов health/CSS прошла без ошибок, в том числе 12 подряд на новом коммите; хеш старого CSS совпадает. Caddy и PostgreSQL сохранили процессы, перезапусков и OOM у новых web/worker нет. После полного bootstrap worker показывал 1,135 ГиБ из 4 ГиБ, на последующем замере — 2,07 ГиБ. Остались текущая версия и один релиз для отката. Проверенный архив и временные исходные выгрузки удалены; общий Docker build cache не изменился (443,2 МБ).
