# WI-023 — Ожидаемые показатели, соперники и автоматическое обновление КХЛ

Kind: change
Canon action: direct-edit

## Outcome
Пользователь видит ожидаемую статистику и проверяемый расчёт каждого будущего матча; статистика автоматически обновляется в 10:00 и 20:00 МСК, линия букмекера обновляется и участвует в маркированной оценке соперника.

- Governing: spec://modules/khl/FEAT-003-khl-projections-and-optimizer#rolling-beta

- Governing: spec://modules/khl/INFRA-003-khl-fonbet-odds#markets

## Scope
In: сохранённые исходные средние и ожидаемые G/A/SOG/PIM/+−, разбор по клику EP, матчевые поправки по проверенной линии, полный Excel, сбор используемых источников по расписанию, проверки, Git и production.
Out: выдуманный ixG, изменение официальных FP, реальные ставки, обход ограничений доступа источников.

## Acceptance
- [ ] В карточке, подсказке EP и полном Excel доступны реальные ожидания и исходный расчёт, максимум две десятичные цифры.
- [ ] Итог EP суммирует отдельные прогнозы матчей; доступные проверенные коэффициенты влияют на прогноз, отсутствие и устаревание обозначены.
- [ ] Скрипт и серверное расписание 10:00/20:00 Europe/Moscow собирают используемые источники с ограниченными пакетами, защитой от дублей и сохранением последних хороших данных.
- [ ] Проверены математика, источники/свежесть, Excel, интерфейс, повторный запуск, память/кэш; выпуск опубликован и проверен.
