# WI-026 — Экономное ежечасное обновление КХЛ на сервере

Kind: change
Canon action: direct-edit

## Outcome
Сервер самостоятельно обновляет доступную статистику КХЛ каждый час в :22 без браузера, с ограниченными ресурсами и явным покрытием полей БД.

## Specs
- Governing: spec://modules/khl/INFRA-001-khl-data-ingestion#runtime
- Governing: spec://modules/khl/INFRA-001-khl-data-ingestion#protocols
- Governing: spec://modules/khl/INFRA-002-khl-storage-and-api#schema

## Scope
In: проверенный HTTP-транспорт, комбинирование доступных источников, инкрементальные загрузки, расписание, ресурсные ограничения, проверки и production.
Out: браузер на сервере, покупка подписок, выдуманные значения отсутствующих метрик, изменение пользовательских сценариев.

## Dependencies
Related: WI-017, WI-023.

## Acceptance
- [ ] Поля текущей БД сопоставлены источникам; неизвестное не заменяется нулём.
- [ ] Транспорт проверен с production; браузер не устанавливается и не запускается.
- [ ] Таймер на сервере активен каждый час в :22; конкурентные циклы исключены.
- [ ] Повторная загрузка идемпотентна; архив и неизменённые данные не перекачиваются каждый час.
- [ ] Проверены ошибки источников, тесты, ресурсы, кэш, дубли и production-состояние.

## Result
В работе. Пользователь отдельно подтвердил запрет браузера на сервере.
