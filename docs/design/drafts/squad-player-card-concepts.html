Маленькая карточка может выглядеть совсем иначе. Те же габариты и данные, два действия — десять разных способов расставить акценты. Все варианты ниже можно нажимать.

Много мелких акцентов в одной белой плитке

Клуб и позиция сверху, круглый портрет, цена сбоку, имя, пять разноцветных прогнозов, три плашки матчей. Удаление в углу, C и VC внизу. Справа — компоновка, восстановленная из текущего компонента.

В обновлённых концептах ниже — только C и прямое удаление. Кнопка замены находится над полем. Габариты и информация сохранены. Наведите на числа, имя или матч — появится подсказка.

Отметьте понравившиеся варианты кнопкой + в углу.

На каждой карточке два действия: C — назначить капитана или снять роль; × — сразу удалить игрока. Замена включается общей кнопкой над полем. Метка уже назначенного VC остаётся информацией, кнопки назначения нет. Игроки и прогнозы демонстрационные; ничего не сохраняется на сервер.

Размеры, состояния и источники

Ширины взяты из SquadPlayerTile в src/components/machete/FantasySquadPlanner.tsx. У исходной карточки нет фиксированной высоты: она вычисляется по содержимому. В этом файле стандартная карточка с пятью прогнозами и тремя матчами служит меркой для всех десяти концептов. На миниатюре используется точный CSS-размер; слева масштабируется только копия для рассматривания. Варианты 57,6 / 60,8 px показывают компактную плитку; отдельный мобильный список приложения здесь не перерабатывается. Сценарии «нет прогноза», «нет в базе», оценочная цена и длинное имя доступны в просмотре «На поле».

Портрет: FotMob, Mohamed Salah, встроен в файл один раз. Остальные игроки используют существующий в приложении fallback с инициалом. Внешние шрифты и библиотеки не подключены. Предварительный поиск: обсуждение fantasy UI на Reddit, карточки и слои на Stack Overflow. Компоновки в этом файле разработаны для текущего Squad.
