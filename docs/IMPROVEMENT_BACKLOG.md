### 12. Единый обработчик ошибок для API-роутов

- **Тип:** надёжность
- **Описание:** Только 11 из 39 роутов имеют `try/catch`. Непойманное исключение

  утечь stack trace.
- **Зачем:** единый формат ошибок, отсутствие утечки stack trace, предсказуемость
  для фронтенда.
- **Где:** новый хелпер-обёртка в `src/lib/` (напр. `withApiHandler`), применить
  ко всем `route.ts`.
- **Сложность:** средняя · **Риск:** низкий · **Приоритет:** средний
- **Согласовать:** дизайн обёртки (HOF vs ручной try/catch); набор кодов ошибок.
