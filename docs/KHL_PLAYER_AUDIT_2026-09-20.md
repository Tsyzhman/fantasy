## Сервер и источники

Используются публичные протоколы/биографии/заявки КХЛ, официальный mobile backend для календаря, Sports для фэнтези и подтверждения биографии, существующий Фонбет для линии. Обновление запускается сервером каждый час в :22 Europe/Moscow. Браузер на сервере не устанавливается и не запускается.

HTTP-запрос свежего протокола в проверке занял 0.37 секунды при пике памяти Python 32 MiB. Сбор идёт последовательно; Node heap ограничен 384 MiB, общий цикл — 30 минутами. Сохранённые ответы сжимаются и ограничены 250 MiB / 7 дней. Повтор неизменённых фактов не создаёт новые статистические значения. Подтверждения травм действуют до двух часов, их история ограничена 30 днями.

Текущие протоколы: первый повтор после полного сопоставления дополнил 161 запись, второй — 0; обработано 65 матчей. Последующий часовой цикл автоматически довёл покрытие до 68 матчей. Травмы: в официальных заявках 34 игрока, 28 присутствуют в нашем каталоге и связаны; остальные шесть не добавлялись в фэнтези искусственно. Отсутствие в списке не объявляется здоровьем.

Предыдущий сезон: разово обработаны 748 протоколов, дополнена 41 история. Теперь расширенная статистика КХЛ есть у всех 540 игроков с загруженной историей Sports; раньше — у 499. Повтор использовал кэш. Разовая операция заняла 558 секунд, максимальный измеренный RSS основного процесса — 241 MiB. [Протокол загрузки архива](../specs/work/evidence/WI-026/archive-backfill.json). Это одноразовое восполнение пробелов; часовые циклы используют ограниченные порции и кэш.

У 16 игроков архивные страницы Sports не содержат достаточной идентичности. Их реальные матчевые суммы восстановлены из официальных протоколов КХЛ; отдельный KHL-only архив заполнил эти показатели без фэнтези-очков и без догадки о пропущенных матчах. Сбой Sports остаётся видимым, остальные источники продолжают работу. Готовый ixG/xGA/GSAx, PP1/PP2, звенья, будущий стартовый вратарь и fullGame не подставляются догадкой.

Свежий завершённый матч может временно иметь шесть пустых таблиц КХЛ. Такой протокол сохраняется в отдельном списке повторов до следующего часа и не останавливает другие матчи. Противоречивые строки Sports (например, нулевое время с результативной передачей) сохраняют последние проверенные факты и не откатывают остальные матчи игрока.

При поиске решений проверены [обсуждение аналитики КХЛ на Reddit](https://www.reddit.com/r/KHLHockey/comments/1wbjgb7/khl_analytics/), [общественная документация mobile API КХЛ](https://github.com/shayypy/khl-api), [обсуждение ограничений curl_cffi на Stack Overflow](https://stackoverflow.com/questions/79678330/getting-blocked-by-cloudflare-with-curl-cffi) и [документация HTTP-клиента](https://curl-cffi.readthedocs.io/en/v0.7.2/impersonate.html). Выбор подтверждён реальными запросами с нашего сервера, а не обещанием из обсуждения.
